# OCAD template

`isom-2017-2-10000.ocd` is the default symbol set of the OCAD export (`--ocad`).
It is OpenOrienteering Mapper's `ISOM 2017-2_10000.omap` symbol set (GPL-3.0-or-later),
saved as OCAD 12 from Mapper, with no objects. Cassini embeds it at build time
and copies its colours, symbols and parameter strings into every exported file.
